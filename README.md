# SolidStart Webapp

A modern 3-page SolidStart webapp with warm earth tones design system.

## Pages

1. **Landing Page** (`/`) - Hero section with headline, subheadline, and CTA button
2. **Features Page** (`/features`) - Grid of 6 feature cards with icons and descriptions
3. **Contact Page** (`/contact`) - Contact form with client-side validation

## Design System

- **Color Palette**: Warm earth tones (terra cotta, warm sand, desert clay)
- **Typography**: Modern sans-serif with clear hierarchy
- **Responsive**: Mobile-first design approach

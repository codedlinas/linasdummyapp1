# CloudPing Landing Page

Design specification and assets for CloudPing - a website uptime monitoring tool.

## Contents

- **DESIGN_SPEC.md** - Complete design specification including layout, color palette, typography, and visual guidelines

## Project Overview

CloudPing is a website uptime monitoring tool that helps users track their website's availability and performance. This repository contains the design direction for a clean, modern single-page landing site.

## Design Highlights

- **Color Scheme:** Blues and whites for trust and professionalism
- **Layout:** Single-page with hero, features, pricing, and footer sections
- **Typography:** Modern sans-serif (Inter/Poppins) for clarity and readability
- **Style:** Minimal, clean, and focused on conversion
